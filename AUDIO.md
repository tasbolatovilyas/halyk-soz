# Озвучка Halyk.Soz

1536 готовых синтезированных записей на казахском: 93,6 минуты, около 32,1 МБ. Голос `kk-KZ-AigulNeural`, исходная речь слегка замедлена при генерации. Файлы MP3 находятся в `public/audio/`, соответствие текстов и файлов — в `public/audio/manifest.json`.

Аудио подготовлено через `edge-tts` и онлайн-сервис чтения Microsoft Edge. В работающем приложении подготовленные записи проигрываются локальным сервером: установленный казахский голос Windows и ключ платного API не нужны. Доступ к приложению по сети всё ещё необходим, если оно открыто с другого устройства. Это не режим офлайн-приложения с сервис-воркером.

## Где слушать

- Карточки слов и фразы уроков.
- Инструкции заданий на казахском и задания на слух.
- Каждое предложение в библиотеке или вся текущая страница последовательно.
- Контекст предложения в окне перевода слова.

Есть пауза, продолжение, повтор с начала, остановка и скорость 1× / 0.8×. Одновременно звучит одна запись. Переход между страницами, заданиями или закрытие окна останавливают прежнее воспроизведение. Звук не запускается автоматически.

Для текста, которого нет в подготовленном каталоге, остаётся резерв через установленный казахский голос браузера. Это может касаться пользовательских слов, добавленных в словарь. При отсутствии файла и резервного голоса приложение показывает сообщение; русский голос за казахский не выдаётся.

## Проверка

- Все 1536 сегментов каталога имеют существующий MP3 с читаемыми аудиопараметрами и положительной длительностью.
- Проверены порядок очереди, пауза/продолжение, скорость, остановка, замена воспроизведения и обработка отсутствующей записи.
- Сервер отдаёт `audio/mpeg` и поддерживает диапазоны байтов для MP3.
- Полной ручной проверки произношения всех записей не было. Перед учебным внедрением записи, имена и исторические термины стоит прослушать с преподавателем казахского.

[Казахские голоса Microsoft](https://learn.microsoft.com/azure/cognitive-services/speech-service/language-support?tabs=tts), [пакет edge-tts](https://pypi.org/project/edge-tts/).
